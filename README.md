## Mô tả
Đây là một trang cá nhân được xây dựng bằng HTML, CSS và JavaScript. Mục tiêu của dự án là tạo một giao diện web đơn giản nhưng đẹp mắt, giới thiệu thông tin cá nhân và nội dung học tập.

## Công nghệ sử dụng
- HTML
- CSS
- JavaScript

## Cấu trúc dự án
- `index.html`: file giao diện chính của trang web
- `style.css`: file chứa các định dạng giao diện
- `script.js`: file xử lý logic và tương tác trên trang

## Cách chạy
1. Tải xuống hoặc clone repository.
2. Mở file `index.html` trong trình duyệt.
